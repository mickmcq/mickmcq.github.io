I've been remiss in providing annual blog posts the last couple of years, but here's one for 2025!

I'm giving a workshop at Google Development Groups on Campus today at WCP Student Activity Center, Room 3.112 at 5PM. This workshop will cover the basics of setting up a local RAG chatbot on your own computer, rather than sending your data to the cloud. Following are the materials for the workshop, in order of presentation.

[Slideshow](https://mickmcquaid.com/localRAGchatbot/index.html) contains the slides for the workshop.

[Slideshow Source](https://mickmcquaid.com/localRAGchatbot/index.qmd) contains the source code for the slideshow.

[localRAGchatbot.qmd](https://mickmcquaid.com/localRAGchatbot/localRAGchatbot.qmd) contains the Quarto source code for building and running the chatbot.

[localRAGchatbot.html](https://mickmcquaid.com/localRAGchatbot/localRAGchatbot.html) contains the rendered HTML for the chatbot.

[Xiao2025.pdf](https://mickmcquaid.com/localRAGchatbot/Xiao2025.pdf) contains the book we'll be ingesting into the chatbot.

[localRAGchatbot2.py](https://mickmcquaid.com/localRAGchatbot/localRAGchatbot2.py) contains the Python source code for the chatbot. This is only used for debugging, in case the above .qmd file doesn't work.
